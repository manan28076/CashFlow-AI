# India Tax Knowledge Base (Official Corpus)

This directory houses official, authoritatively verified Indian income tax documents downloaded from official government sources (such as [incometax.gov.in](https://www.incometax.gov.in/iec/foportal/)).

Per the CashFlow AI strict **Anti-Hallucination Guardrails**, the AI system will **NEVER** invent tax slabs, deduction limits, section numbers, or deadlines from memory. All Indian tax answers generated by CashFlow AI's financial copilot originate exclusively from markdown and text files placed within this directory.

---

## Required Front-Matter Format

Every document added to this folder **MUST** begin with YAML front-matter containing the following required fields:

```markdown
---
title: "Income Tax Slabs & Rates for FY 2025-26 (AY 2026-27)"
sourceUrl: "https://www.incometax.gov.in/iec/foportal/income-tax-slabs"
retrievedOn: "2026-04-01"
financialYear: "2025-26"
---

# Official Document Content Begins Here
...
```

### Front-Matter Field Specifications

| Field | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | Official publication title of the rule, circular, or slab schedule. |
| `sourceUrl` | `string` | Exact HTTPS URL from `incometax.gov.in` or official Gazette notifications. |
| `retrievedOn` | `string` | ISO date (`YYYY-MM-DD`) when the document was retrieved from the official portal. |
| `financialYear` | `string` | Financial Year applicable to the document (e.g., `"2025-26"` or `"2024-25"`). |

## Recommended Official Documents to Ingest

To populate this knowledge base, download or export the following official resources:

1. **New Tax Regime Slabs (Section 115BAC)**
   - Source: [Income Tax Department — Tax Rates](https://www.incometax.gov.in)
   - Scope: Income brackets, slab percentages, standard deduction limits for salaried individuals.
2. **Old vs New Tax Regime Deductions & Exemptions**
   - Source: [Income Tax Department — Deductions Guide](https://www.incometax.gov.in)
   - Scope: Chapter VI-A deductions (Section 80C, 80D, 80CCD, 80G), HRA exemptions, and eligibility under each regime.
3. **Rebate Under Section 87A**
   - Source: [Income Tax Department — Tax Rebates](https://www.incometax.gov.in)
   - Scope: Zero-tax thresholds for resident individuals under both regimes.
4. **Capital Gains Tax Rates**
   - Source: [Income Tax Department — Capital Gains Schedule](https://www.incometax.gov.in)
   - Scope: Short-term and long-term capital gains on listed equities, debt mutual funds, and immovable property.
5. **ITR Filing Due Dates & Compliance Calendar**
   - Source: [Income Tax Department — Tax Calendar](https://www.incometax.gov.in)
   - Scope: Due dates for filing individual non-audit returns (July 31) and audit cases.

## Ingesting Documents into the Vector Database

Once you place markdown files in this folder, execute the ingestion pipeline:

```bash
cd backend
npm run ingest:knowledge
```

The ingestion pipeline will:
1. Parse front-matter and validate required fields (`title`, `sourceUrl`, `retrievedOn`, `financialYear`).
2. Compute a SHA-256 `contentHash` to skip unchanged documents.
3. Chunk content cleanly on paragraph boundaries with sliding overlap.
4. Generate vector embeddings using Google Gemini's official `text-embedding-004` model.
5. Upsert chunks into PostgreSQL for in-memory cosine ranking.

*Note: If this folder contains no documents or only this README, the RAG tool will truthfully respond with "knowledge base is empty".*
